# 01 插件双面结构与打包

dsh 外部插件是**双面包**：一个 npm 包同时提供 node 半（host 侧）和浏览器半
（client 侧），通过 `cordis.patch.yml` 告诉 Loader 插入双面行。参照
`@deepseek-ai/dsh-client-hmr` 的同构机制。

## 双面构成

| 面 | 入口 | 产物 | 职责 |
|---|---|---|---|
| node 半 | `src/index.ts` | `lib/index.js`（ESM） | `apply(ctx)` 注册 RPC 通道、服务 |
| 浏览器半 | `src/client/index.ts` | `lib/client.js`（CJS） | `apply(ctx)` 挂载 UI（slots / locale 等） |

```ts
// node 半：注册通道（权限 = trusted-host，只读类操作）
export const inject = ['connection']
export function apply(ctx: Context): void {
  ctx.effect(() => ctx.connection.rpc.handle('/textviewer', createTextviewerHandler()), '...')
}

// 浏览器半：挂载 UI
export const inject = ['slots', 'locale', 'connection']
export function apply(ctx: Context): void {
  ctx.effect(() => ctx.locale.register(NS, { zh, en }), '...')
  ctx.slots.inject('shell.overlay', () => ctx.slots.register({ name: 'shell.overlay', id: '...', locale: NS, order: 1000, inject: () => ({...}) }, DockComponent))
}
```

## 关键文件

- **`cordis.patch.yml`**：`- insert: { id: <短名>, name: '@scope/<pkg>' }` 一行，
  让 Loader 激活 node 半并把浏览器半放进 `window.__DSH_BOOT__` roster
- **`package.json`**：`exports` 暴露 `.`（node）与 `./client`（浏览器半）；
  `dsh.client.inject` 列出需要的官方客户端模块（`connection/locale/runtime/
  ui-slots/ui-primitives/api-remotes/typert-*/host-apiproxy/ui-layout`）；
  `files: ["lib/**/*", "cordis.patch.yml"]`（**懒渲染包等附加 lib 文件自动包含**）
- **`tsdown.config.ts`**：node 半 ESM + 浏览器半 CJS（banner 包
  `window.__ModuleLoader__.load({ id, factory: (require) => {...} })`，intro 定义
  `module/exports`）；`BASELINE_EXTERNALS`（react、react/jsx-runtime、
  @deepseek-ai/* 等 shell 已注入的模块）绝不内联，其余全部内联
- **CSS Modules**：虚拟 id 管线（lightningcss 编译成内容哈希类名 + 注入
  `<style data-plugin-css>`），见 11-样式主题

## 类型接线

- tsconfig `paths` 指向 harness 源码的 `lib/types`（`D:/framework/deepseek-harness/
  packages/...`），本地源码即类型真相
- 新 harness API：`ctx.slots` 增强在 `dsh-client-ui-renderer`、`useSessions`
  标准 prop 在 `dsh-client-ui-session/client`、`rpc.handle` 已是两参（authority
  参数已移除，信任靠物理载体）
- `LocaleNamespaceMap` 模块增强（`declare module '@deepseek-ai/dsh-client-ui-slots'`）
  必须写在 `locales.ts`，否则 `ctx.locale.register(NS, ...)` 与 `PropsLocale<typeof NS>`
  都不通过类型检查

## 注意点

- 浏览器半输出是 CJS 闭包工厂，**单文件契约**：任何会触发 code-split 的写法
  （动态 import）都会破坏 `lib/client.js` 形态——要拆重代码用「懒渲染包」方案
  （见 09-文本查看器-懒加载渲染包），而不是动态 import
- 两个半共用一份 tsconfig（paths 含 node 类型），浏览器代码里 `require` 可用
  （loader 注入）；`process.env.NODE_ENV` 等由 define 替换
- `.ts` 文件里写 JSX 会报"未终止的正则字面量"——**带 JSX 必须用 `.tsx` 扩展名**
