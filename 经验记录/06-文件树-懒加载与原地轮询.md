# 06 文件树-懒加载与原地轮询

文件导航区的成熟形态（fileexplorer 与 textviewer 同款）：**单棵懒加载树**，
不是渐进式切换目录的面包屑导航。用户要求"直接就一颗树，全在上面"。

## 数据结构

```ts
interface Node {
  name: string; path: string; kind: 'file' | 'dir'
  git?: 'M' | 'D' | 'A'          // 按需
  children: Node[] | null        // null = 未展开过（懒加载标记）
  expanded: boolean
  truncated: boolean             // 该层被 host 截断
}
```

## 三个核心纯函数

- `mergeNodes(existing, fresh, truncated)`：合并一层新数据，**保留旧节点
  的 children/expanded/truncated**（轮询刷新不会把树收回去）
- `mapAt(nodes, path, fn)`：按路径递归定位并改写单个节点（展开/收起的
  唯一变更原语）
- `collectExpandedPaths(nodes)`：收集所有已展开目录（BFS，根层优先）——
  轮询时逐个原地刷新

## 行为

- 根层自动加载；点击目录首次展开才 `list` 该层（in-flight Set 防重复请求）
- 2s 轮询：根层 + 全部已展开层原地刷新；`visibilitychange` 回前台补刷一次
- `nodesRef` 实时镜像 + `updateNodes(fn)` 走 ref 更新——**避免闭包捕获
  旧状态**（轮询/异步回调里读 state 会拿到过期树）
- 隐藏条目在 merge 时过滤（v1 不上表面）
- 空根渲染空（`<></>`），初始加载失败显示错误行（`error` state），
  已展示数据的轮询失败静默保留旧树

## 行渲染

- 目录行：twisty（chevron 展开/收起）；文件行：圆点占位同列对齐
- 缩进 `paddingLeft = 6 + depth * 14`（内联，几何值）；行高亮复用
  `.rowSelected`；键盘 Enter/空格等效点击（`role="button"` + tabIndex）
- 截断层尾显示省略提示行

## 注意点

- 折叠/收起只改 `expanded` 标志，**不卸载 children**（再次展开零请求，
  且轮询可以继续刷新已收起层——按需取舍，当前实现只刷展开层）
- 不要用 path 前缀当 key 的替代：path 是绝对路径，跨工作区切换时树整体
  reset（effect 依赖 root）
