# 02 终端-测试说明

套件：`ui-cw-terminal/tests/host.spec.ts`，**14 个用例**。直调 handler 工厂；
PTY 行为通过注入的伪 ConPTY 层驱动（真实 ConPTY 不在 CI 环境断言，
重放/快照语义在伪层上精确复现）。

## 用例逐项

### terminal create/list（4 个）

- 无记录工作区**自动创建默认终端**（no-record → auto-create 约定）
- 显式 cwd + 标题创建第二个终端
- 未限定工作区拒绝
- 每工作区容量上限强制

### terminal send/read/clear（7 个）

- 键入输入转发到 PTY
- 自客户端 offset 起返回**增量输出**（转录只追加）
- 光标跌出 scrollback 头时信号 reset
- 清屏：缓冲清空 + 光标复位（clear = 真清屏）
- **吞并 ConPTY resize 重绘**：屏幕重画只在 reset 后作为一次快照下发
- 无 show-cursor 到达时按普通输出释放（不是重绘）
- 进程退出状态上报 + 退出后拒绝输入

### terminal close/teardown（3 个）

- 关闭会话并从工作区列表移除
- 未知会话拒绝
- terminateAll 终止全部会话

## 手工验收清单（每次改动后）

- [ ] 默认收起为 30px 条；标题栏整条点击切换（选区/拖拽守卫不误触）
- [ ] 输入回显无残片（`{{`、`;44h` 类碎片 = 重放未吞净）
- [ ] clear 清屏；新建/清屏入口在标签列表底部；标签列表在右侧；关闭行为
- [ ] 高度拖拽：80px 下限（≠ 30px 收起态）；拖拽时无重放风暴
- [ ] 无记录会话自动新建；会话内存态（刷新即失）
- [ ] **让位联动**：终端展开/收起时右 dock（textviewer）同步升降
  （依赖 `--dsh-terminal-height` 发布到 documentElement）
- [ ] 主题：背景/ANSI 色/光标/选区跟随明暗切换
- [ ] 底部面板不挤压侧边 dock（宽度变量联动）
