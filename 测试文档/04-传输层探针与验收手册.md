# 04 传输层探针与验收手册

浏览器之外验证插件全链路的可复用配方（PowerShell）。原则：**探针用完即删、
不改插件代码、测试服务器由用户授权后拉起**。

## 配方 1：cookie 换发 + RPC 信封直调

RPC 端点带浏览器信任栅栏与页面认证：命令行必须先换 cookie 再 POST。

```powershell
$session = New-Object Microsoft.PowerShell.Commands.WebRequestSession
$null = Invoke-WebRequest -Uri 'http://127.0.0.1:3099/?token=<页面token>' `
  -WebSession $session -UseBasicParsing -TimeoutSec 8   # 换 dsh-auth-* cookie

function Rpc([string]$method, $payload) {
  $body = @{ type='client-request'; rpcId="probe-$([guid]::NewGuid().ToString('N').Substring(0,8))";
            method=$method; payload=$payload } | ConvertTo-Json -Depth 6
  $r = Invoke-WebRequest -Uri "http://127.0.0.1:3099/textviewer/$method" -Method Post `
    -Body $body -ContentType 'application/json' -WebSession $session -UseBasicParsing -TimeoutSec 30
  return $r.Content | ConvertFrom-Json
}
Rpc 'read-text' @{ root='D:\...'; path='D:\...\file.txt' }   # 检查 .result.ok / .result.value
Rpc 'list' @{}    # textviewer 已移除 list → 应返回 bad-request
```

要点：

- 401 = 认证没过（cookie 缺失）；403 = 信任栅栏拒绝（Host/Origin）
- 信封 `rpcId` 每次唯一，响应带同 id
- 工作区越界探测：读 root 之外文件 → `directory-unreadable`（应含 escapes）

## 配方 2：roster 与 combo bundle 检查

插件 client bundle 走 **combo URL**（`/plugins/??a/client.js,b/client.js&rev=`），
单文件 URL 404 是**正常**的，别被误导。

```powershell
$r = Invoke-WebRequest -Uri 'http://127.0.0.1:3099/?token=<token>' -UseBasicParsing
$r.Content.Contains('ui-cw-textviewer')   # roster 是否含插件
# 取含目标插件 id 的 combo 串（注意 &amp; 反转义）后整体拉取
$m = [regex]::Match($r.Content, '(/plugins/\?\?[^"'']*ui-cw-textviewer[^"'']*)')
$combo = $m.Groups[1].Value -replace '&amp;','&'
(Invoke-WebRequest -Uri ("http://127.0.0.1:3099" + $combo)).Content.Contains('ui-cw-textviewer')
```

## 配方 3：构建产物断言

- bundle 关键串：`Get-Content lib\client.js -Raw` 后 `.Contains('--dsh-terminal-height')`
  等——怀疑"改了没生效"时先查产物再查服务器
- 防回归串：textviewer 不应含 `100vh`（面板高度由 top+bottom 定）

## 验收节奏（每次迭代）

1. `pnpm typecheck` + `pnpm test` + `pnpm build` 全绿
2. 重启 3099 测试服 → 浏览器验证（L5 清单见各插件文档）
3. 用户确认 → 提交（`type: 中文摘要` + 有序要点）→ 正式版 publish.ps1
4. 三个插件联动改动（事件桥/几何契约）时必须**同批发布**，
   只发一个会断链（见各插件"让位联动"依赖说明）
