# 测试文档集合（总览与运行）

本集合与三个插件仓库的测试代码同步维护，回答三个问题：**每个插件测了什么、
怎么跑、改完怎么验收**。与 `经验记录/04-测试策略` 互补：那边讲方法论与踩坑，
这边是每个插件的事实清单。

## 测试分层

| 层 | 手段 | 覆盖 | 执行时机 |
|---|---|---|---|
| L1 单元/直测 | vitest 直调 handler 工厂（无 ctx、无网络） | 解析纯函数、端点行为、错误分支 | `pnpm test`（每个插件） |
| L2 真环境集成 | 临时真实 git 仓库 / 真实文件 | git 状态、编码、分块 | 同上（`skipIf(!hasGit)` 守卫） |
| L3 传输层探针 | PowerShell 带 cookie 的 HTTP RPC 信封 | 路由挂载、认证、端点全链路 | 改动端点后手工跑（见 04 手册） |
| L4 渲染管线 | Node 模拟 loader 求值 | 懒渲染包可执行、高亮/渲染输出 | 改动渲染包后（见 03） |
| L5 手工验收 | 浏览器视觉确认 | 布局、交互、主题、跨插件联动 | 每次迭代发布前（见各插件文档） |

## 运行命令

```powershell
# 每个插件目录内
pnpm typecheck   # tsc --noEmit（提交门槛）
pnpm test        # vitest run
pnpm build       # 三件套产物（textviewer 另产 lib/renderer.js）
```
