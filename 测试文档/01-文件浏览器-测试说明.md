# 01 文件浏览器-测试说明

套件：`ui-cw-fileexplorer/tests/host.spec.ts`，**41 个用例**（34 直测 + 7 真实
git，`it.skipIf(!hasGit)` 守卫）。直调 `createFileExplorerHandler` 工厂，
无 cordis、无网络；临时目录真实读写。

## 用例逐项

### fileexplorer list（20 个）

- 目录在前、名称排序、size/mtime/hidden 标志
- 根到目标的面包屑链（根 crumb 携带完整路径）
- 工作区锁定：root 限界 + crumb 链裁剪
- attrib 输出解析（隐藏路径集合）
- porcelain 三态解析（M/D/A + 未跟踪目录尾部斜杠）
- 请求 git 时附加状态到条目
- **porcelain 状态按 REPO 根键控**：子目录层级同样匹配（pathspec 回归）
- 无自身仓库的层级无任何状态（用户铁律：不聚合父层）
- 文件夹唯一变化是内嵌仓库时不打徽标（两种形态：未跟踪目录 / tracked gitlink）
- maxEntries 截断保留名称排序头部
- 无 path 时默认 host cwd
- 错误分支：未知端点 bad-request / 缺失目录 / 文件目标 / 相对路径
  directory-unreadable / 调用方中止 cancelled

### git snapshot（13 个，其中 6 个真实 git）

- git log pretty 解析为提交行
- **剥离 git 每条记录后追加的换行**（云端标记匹配不上的历史根因，回归测试）
- 多行提交正文解析与边缘修剪、无正文省略 body 字段
- git status 分支行解析（ahead/behind 各形态）
- 快照端点：分支/上游/领先落后/提交分页
- 云端领先时暴露上游 tip（remoteTip）
- 提交 skip/limit 提交与钳制
- 指定分支视图 + 未知 ref 拒绝
- 非仓库根分类、git 缺失分类
- file-history 端点 + 越出锁定根的拒绝
- open 端点：未限定路径拒绝、打开失败上抛
- **冷却合并**：同路径快速重复打开合并、失败即释放冷却槽
- 未限定的 git root 拒绝

### 真实 git 集成（7 个，skipIf）

- 多提交真实文件历史
- 真实仓库快照 + 云端领先边界（真实 remote）
- 子目录逐文件状态（pathspec 回归）
- 其余为快照端点/历史/分支视图等走真实 git 的版本

## 手工验收清单（每次改动后）

- [ ] 树：根层自动加载；展开目录懒加载；2s 轮询刷新不收起已展开层
- [ ] 徽标：文件行 M/D/A；进入子目录逐文件状态正确；嵌套仓库不污染父级
- [ ] 云端领先：behind>0 时顶部"云端领先 N 个提交"标记 + 位置图标
- [ ] 提交行点击展开正文；滚动到底无限加载
- [ ] 历史抽屉：点文件 → 该文件提交历史；最新变更蓝标
- [ ] 布局：宽度拖拽（180–640px）、两抽屉独立收起 + 高度把手、整体收起 rail
- [ ] 文件行点击 → 文本查看器打开（跨插件事件，需 textviewer 同在）
- [ ] 主题切换：徽标色/选中色/滚动条跟随
